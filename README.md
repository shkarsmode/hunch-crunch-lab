# Hunch Crunch Lab

Play the simulations from the [Hunch Crunch](https://www.youtube.com/@HunchCrunch) videos in your browser. Got a hunch? Play it.

- **Two ants, same 2 rules**: two Langton's ants on one grid. They come home at step 84,876.
- **Real coin or fake?**: try to type flips that fool 10,000 real coins.
- **Fill the sticker album**: rip packs until it's full.

Next.js 16, React 19, Tailwind 4, Supabase (Google sign-in, database), Patreon for supporters. Every simulation runs in the browser.

Setup, environment variables and the cost and abuse notes are in [SETUP.md](SETUP.md).

```
npm install
npm run dev
```
